# Boundary Conditions: TPZBndCond

This page is a catalog of the NeoPZ Boundary Condition structure, for which **no** "invented" code with unsupported methods should be generated.

## `TPZBndCond`
**Header**: `#include "TPZBndCond.h"`

Represents the boundary conditions of a finite element problem in NeoPZ.
In NeoPZ, a boundary condition object is **never** instantiated directly with `new TPZBndCond`. It is always generated by the material of that domain, using the `CreateBC()` method.

### Usage example (Dirichlet and Neumann)
```cpp
#include "TPZBndCond.h"
#include "Poisson/TPZMatPoisson.h" // Example of a material that generates the BC
#include "pzvec.h"
#include "pzfmatrix.h"

int main() {
    // 1. Instantiating the material (main domain)
    int mat_id = 1;
    int dim = 2;
    auto *material = new TPZMatPoisson<STATE>(mat_id, dim);

    // 2. Boundary condition parameters
    int bc_id = -1; // ID of the geometric boundary

    // Common types:
    // 0 = Dirichlet (imposed value of the function)
    // 1 = Neumann (imposed value of the derivative/flux)
    int typeDirichlet = 0;

    // Value matrices
    TPZFMatrix<STATE> val1(1, 1, 0.0); // Used in Robin (mixed) conditions
    TPZVec<STATE> val2(1, 10.0);       // The imposed scalar value (e.g. temperature = 10.0)

    // 3. The material is the one that CREATES the TPZBndCond object
    TPZBndCondT<STATE> *bnd = material->CreateBC(material, bc_id, typeDirichlet, val1, val2);

    return 0;
}
```
